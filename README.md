# smart-cash-flow

Sistema de control y análisis de flujo de efectivo evolucionado desde una plantilla de Excel hacia un enfoque de Ingeniería de Software, Datos e IA.

## Estado actual: v1 (Excel)
- **Archivo:** `Smart_cash_flow.xlsx` (versión saneada sin información sensible).
- **Alcance:** control de movimientos financieros, clasificaciones, cierres por periodo y reportes base.

## Roadmap técnico
1. **v1 — Excel:** plantilla limpia y documentada (actual).
2. **v2 — SQL:** modelado relacional y consultas estructuradas.
3. **v3 — Python:** automatización de validación, limpieza y flujo de datos.
